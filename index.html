About the Flash Cards App

In this Flash Cards App, you can create your decks of cards to memorize study materials and practice them. It’s a student project for the TripleTen AI-Assisted Software Engineering course.

When creating a deck of cards, you have to paste/type JSON following this schema: 

{
  "name": "Name",
  "cards": [
    {
      "question": "Question?",
      "answer": "Answer"
    },
    ...
  ]
}
