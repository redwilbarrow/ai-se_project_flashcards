# Flashcard App

A browser-based flashcard study app built during TripleTen's AI-Assisted Software Engineering program. The app helps software engineering students review web development concepts through organized decks, carousel-style navigation, and card flipping.

## Overview

Briefly explain the goal of the project, who it is for, and what problem it solves.

## Features

- Browse built-in study decks
- Open each deck in a carousel view
- Navigate between flashcards
- Flip cards to reveal answers
- Delete decks from the visible deck list
- Includes a New Deck button for planned custom deck creation
- Handles missing routes with a 404-style view

## Planned Improvements

- Create custom decks
- Add, edit, and delete individual cards
- Save decks with local storage
- Add progress tracking
- Add search or filtering
- Improve accessibility and keyboard navigation

## Technologies Used

- HTML5
- CSS3
- JavaScript ES modules
- Normalize.css
- Google Fonts
- SVG icons

## Project Structure

Briefly describe the main files/folders:

- `index.html` - main page structure
- `assets/css/style.css` - app styling
- `assets/js/decks.js` - flashcard deck data
- `assets/js/carousel.js` - carousel behavior
- `assets/js/index.js` - routing and rendering logic

## Getting Started

Explain how to run it locally:
