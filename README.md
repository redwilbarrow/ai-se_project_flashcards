# Flashcard App

A browser-based flashcard app for studying software engineering concepts. Built as part of TripleTen’s AI-Assisted Software Engineering program, it helps users review topics through organized decks, card flipping, and carousel-style navigation.

## Features

- Study from prebuilt flashcard decks
- Navigate cards in a carousel view
- Flip cards to reveal answers
- Remove decks from the visible gallery
- View a not-found page for invalid routes
- Modular JavaScript structure with template-based rendering

## Technologies Used

- HTML
- CSS
- JavaScript
- Google Fonts
- SVG assets
